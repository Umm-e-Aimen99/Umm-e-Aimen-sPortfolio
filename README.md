# Umm-e-Aimen — Personal Portfolio

A responsive personal portfolio built as a Day 1 AI-assisted web development project.

## Included
- Responsive desktop/tablet/mobile layout
- Modern dark/light theme
- Mobile navigation
- Scroll reveal animations
- Active section navigation
- Project category filtering
- Interactive project case-study modal
- Copy-email action with toast notification
- Accessible semantic structure
- No framework required — plain HTML, CSS and JavaScript

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## AI-assisted workflow
For the Day 1 task, use an AI development tool such as Google AI Studio, Lovable, or Replit to:
1. Generate/iterate on the UI.
2. Ask the AI to improve responsive behavior.
3. Ask it to review accessibility and semantic HTML.
4. Test every interaction and fix issues through prompts.
5. Keep your own final edits and understand the code.

## Important accuracy note
The portfolio content is based on the supplied resume. It deliberately describes skills as foundations/basic/currently learning rather than overstating professional experience.
